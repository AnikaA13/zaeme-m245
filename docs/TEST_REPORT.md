## Was die Tests belegen

**Formatierung und Git-Prüfung.** Der erste Aufruf von `npm run format:check` meldete 23 Dateien mit CRLF (Exit 1). Der Kontrolllauf mit `--end-of-line auto` bestand. Der auf Commit verschobene zusammengesetzte FK und UNIQUE(user_id) sichern die Invarianten. pgTAP prüfte kanonische Namen, 100/101 Unicode-Codepunkte, Hashlänge, Warnfrist und blockierte administrative Kontolöschung. Ein unbestätigtes Konto scheiterte am Login. pgTAP prüfte zusätzlich eine unbestätigte Identität unter der Rolle authenticated. Haushaltsdaten von A/B/C waren von D in H2 getrennt. Wiederholungen derselben Einladungserstellung lieferten ID und Verfall erneut. Die Vorschau blieb auf den Haushaltsnamen beschränkt.
