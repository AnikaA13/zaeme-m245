# Vorläufige UX-Spezifikation

Die Mobile-Variante ist im separat geführten MVP-Entwurf als
UX-Referenz festgehalten. Die vorhandene App verwendet Schweizer
Standarddeutsch, eine responsive Mobile-first-Anordnung und sichtbare
Tastaturfokuszustände.

| Markenfarbe   | Provisorischer Wert |
| ------------- | ------------------- |
| Dunkelviolett | `#1C1840`           |
| Violett       | `#4B3FA8`           |
| Mintgrün      | `#7AD3A8`           |
| Creme         | `#FBF9F1`           |
| Koralle       | `#FF7A7A`           |

Die Farbwerte stehen in `src/styles/tokens.css`. Der Einstieg verwendet
vorübergehend den Schriftzug «zäme». Das Originallogo und die Referenzdatei
`references/zaeme_mobile.html` fehlen im Checkout.

Endgültige Design-Tokens, Bildschirmaufteilungen, Navigation und
Interaktionen bleiben bis zur UX-Freigabe offen.
